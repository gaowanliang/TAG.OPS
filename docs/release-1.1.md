# TAG.OPS 1.1

Windows 64 位 DirectML 发布版，支持通过 DirectML 使用兼容的 NVIDIA、AMD、Intel 显卡，并保留 CPU 后端。

- 自动选择当前后端中专用显存最大的显卡，完善手动设备选择。
- 增加模型载入先验、GPU 活动核验和算子执行诊断，完善引擎名称识别。
- 增加系统、驱动、模型加载、GPU 活动和对话框日志，便于排查问题。
- 浏览文件夹和确认提示使用后端调用的 Windows 系统对话框。
- 提醒分类查看仅适用于文件夹模式，直接拖入图片不支持分类查看。
- 随包提供 `data/tags_tr.yaml` 中文标签翻译表，可直接编辑；程序内另保留默认副本。

解压完整 `TagOps` 文件夹后运行 `TagOps.exe`。可复用旧版 `models` 文件夹，避免重复下载。模型、日志和历史记录保存在程序旁边。

遇到问题时可提供 `logs` 文件夹，其中 `.log` 保存运行日志，`ort-profiles` 保存载入先验的算子执行记录。
